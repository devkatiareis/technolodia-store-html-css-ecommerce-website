# technolodia-store-html-css-ecommerce-website

Technolodia Store is a static front-end e-commerce MVP focused on technology and consumer electronics, designed with a modern, clean, and high-contrast interface based on a bento grid design system.

A modern e-commerce template tailored for technology and electronics stores, built with a focus on **Mobile-First**, accessibility (**WCAG 2.1 AA**), performance (CLS prevention), and front-end architectural standards good practices.

## 🚀 Technologies Used

* **HTML5**: Semantic and accessible markup (compatible with WCAG 2.1 AA guidelines).
* **CSS3**: Modular styling with CSS variables (Design Tokens), Flexbox, and CSS Grid.
* **JavaScript**: Interactivity and dynamic logic for interface components.

* **Typography**:
* Display / Headings: *Outfit* (`--ff-display`)
* Body / UI: *Plus Jakarta Sans* (`--ff-body`)
* Monospace: *Roboto Mono* (`--ff-mono`)

## 🎨 Design System & Tokens

The project uses a robust set of centralized CSS variables for visual standardization:

* **Surfaces & Backgrounds**: Clean neutral tones like `--paper` (`#FFFFFF`), `--bg` (`#F8FAFC`), and subtle surfaces (`--bg-soft`, `--bg-deep`).
* **Ink & Typography**: Text colors structured into `--ink` (`#0F172A`), `--ink-soft`, `--ink-mute`, and `--ink-faint`.
* **Primary Identity**: Indigo variations (`--indigo`, `--indigo-deep`, `--indigo-soft`, `--indigo-line`).
* **Bento Cards**: Themed colors for highlight blocks (Blue, Purple, Orange, Green, and Black).
* **Spacing & Radii**: Modular spacing scales (`--s1` to `--s10`) and standardized border radii (`--r-sm`, `--r`, `--r-lg`, `--r-xl`).

## ⚙️ How to Run the Project

1. Clone the repository or download the files to your computer.
2. Open the `index.html` file directly in your preferred web browser (Google Chrome, Firefox, Edge, etc.).
3. *(Optional)* Use a local server extension, such as **Live Server** in VS Code, for an enhanced front-end development experience.
